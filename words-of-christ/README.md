# The Red Letters — four Gospel read-aloud reader

**Live website:** https://abcentech.github.io/Psalm-119-website/words-of-christ/

This is a separate GitHub Pages-hosted Scripture reader, not the KidsInspiring Nation website. The **entire King James Version red-letter corpus is embedded in the HTML file**: 39,350 words, 1,943 speech segments, 85 reading chapters across John, Matthew, Mark and Luke. It does not fetch chapter data from an API. The red-letter boundaries are editorial and may differ by Bible edition.

## Reading

Select a Gospel and chapter; tap a verse number to begin. You can choose:
- **This chapter only** — stops at the chapter boundary.
- **Entire book, continuously** — reads sequentially to the end of the selected Gospel, including moving to the next chapter automatically.
- **All four Gospels, continuously** — advances through each available chapter.
- **Repeat selected verse** — repeats the selected verse (including split speech segments) indefinitely or 3, 5, 10 or 20 times.

Enter a command in the **Tell the reader what to do** field, including:
- `Read John` — starts John at chapter 1 and reads all of John without requiring another click.
- `Read John 3`, `Read John chapter 3`, `Read Luke 5:12`.
- `Loop John 3:16`, `Repeat John 3:16 five times`, `Loop John 3:16-18`, `Loop this verse`.
- `Pause`, `Continue`, and `Stop`.

The microphone command button uses the browser Web Speech Recognition implementation, **only if supported**; typing commands works without it.

## Voices, real recordings and limitations

There are **two separate narration engines**:

1. **Natural studio-style voice** (default): prerecorded British Emma and American Heart narration generated with the permissively licensed Kokoro neural TTS model. Each verse has true recorded audio with word timestamps. Playback uses HTML5 audio, so repeating a verse is a reliable media seek rather than restarting Android Web Speech.
2. **Device voice**: fallback browser `speechSynthesis` with installed English voices. On some Android devices these can sound robotic or omit end/boundary events. It may pause when the screen is locked.

The British and American natural recordings are generated by the `.github/workflows/neural-audio.yml` matrix pipeline. It covers all **85 chapters with red-letter passages** across John, Matthew, Mark and Luke (170 chapter files), and the publish job checks every chapter and timestamp before releasing the complete batch. The complete audio collection is **only available after that workflow succeeds**. A verified John 1 sample for both accents was published first.

**Nigerian English:** `en-NG` remains an honest device voice option, not a relabeled British/American neural recording. A reliable, natural Nigerian neural voice has **not yet been deployed**. Options such as Nigerian-language fine-tuned models exist, but require additional validation and compute or an authorized provider.

## Commands and looping

- `Read John` — starts John 1 and progresses through the book, switching chapters automatically.
- `Read John 3` and `Read Matthew chapter 5` — start at the given chapter and continue the book.
- `Loop John 3:16` — repeatedly plays the selected verse until stopped.
- `Repeat John 3:16 five times` — repeats exactly five times, then stops.
- **↻ Repeat** is now available directly beside every saying, without typing.
- `Stop`, `Pause`, and `Continue` are also recognized by typed commands.

The interface offers voice previews, reading-speed control, search, chapter progress and optional microphone input when supported. The complete KJV red-letter text is bundled into `index.html` with no chapter API dependencies.

## Testing

`.github/workflows/red-letters-tests.yml` runs real headless Chromium regression tests. They confirm that chapter and book navigation load, the natural British/American recording metadata loads, three verse repetitions complete, infinite looping stops, the continuous John command starts, and search operates.

## Hosting and deployment

The source is on the `gh-pages` branch at `words-of-christ/index.html`. The standalone site uses only static HTML, CSS and JavaScript, with no external runtime API calls for Scripture. This branch is configured for GitHub Pages and its Pages build workflow should complete after changes.
